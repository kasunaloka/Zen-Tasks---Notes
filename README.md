# Zen Tasks & Notes

A Cosine mod for Zen Browser. Open **Tasks & Notes** beside the `+` button at the bottom of the sidebar. Use **Tasks** to add and check off to-dos. Use **Notes** to write multiline notes and optionally attach the current web page. Both lists support editing and deletion.

Each Space has its own task and note lists. Saved entries stay in the local Zen profile after a restart. Drafts stay with their original Space until saved, canceled, or the browser window closes. The button appears in regular windows.

## Install with Cosine

1. Open **Settings → Cosine Mods** and find **Add an unpublished mod**.
2. Enter the GitHub URL of this folder once the files are pushed, for example `https://github.com/OWNER/REPOSITORY/tree/main/zen-tasks-and-notes`. If you publish these four files in their own repository, enter `OWNER/REPOSITORY`.
3. Enable custom JavaScript mods in Cosine if required, then install and enable **Zen Tasks & Notes**. Restart Zen to load the button.

The mod targets the Zen 1.23b sidebar footer and Space-switch event. It has its own Cosine ID and can run alongside **Zen Tab Group Colors**.

## Save a page with a note

Open an HTTP or HTTPS page, select **Notes**, and choose **Attach current page** before saving. The panel shows the page title so you can check which link will be saved. Choose **Remove page** to clear the attachment. Clicking a saved page title opens it in a new tab.

Use the Tab key to reach the sidebar button and panel controls, and Escape to close the panel. Enter submits a task. Use **Save note** to submit a note, so Enter can still add a new line.
